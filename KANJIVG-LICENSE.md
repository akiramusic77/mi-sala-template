# Kana stroke data

The paths in kana-strokes.js are from KanjiVG, copyright Ulrich Apel.
Source: https://kanjivg.tagaini.net
License: Creative Commons Attribution-ShareAlike 3.0
https://creativecommons.org/licenses/by-sa/3.0/

The path data is distributed without changing the strokes. The application scales and positions the paths for its practice guide. The guide checks stroke start, end, order and direction, not the complete drawn shape.
